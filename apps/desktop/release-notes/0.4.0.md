## New

- **Global hotkeys.** Under Settings > Hotkeys you can set a key combination that mutes or unmutes your microphone and one that turns the sound off or on. They work across the whole system, also while a game or another program has the focus. A short tone confirms what the key did. A key without Ctrl, Alt, Shift or Win is accepted for the function keys (F13 to F24 are what a Stream Deck or G Hub sends), the number pad and the media keys. Hotkeys are kept per device. On Linux they work with X11 only.
- **Push-to-talk works across the whole system (Windows).** While you are in a voice channel with push-to-talk, your key works whichever window has the focus, in games too, and other programs still get it. On Linux the key still works only while a Squorli window has the focus.
- **Control from a Stream Deck, G Hub or any macro tool.** Besides sending one of the hotkeys, a device can open a link such as `squorli://control/mic-toggle` or run the app with `--control=mic-toggle`; the running app carries the command out without bringing its window to the front. Settings > Hotkeys lists all six commands (microphone toggle, on, off; sound toggle, off, on) with a copy button each.
- **Arrange your servers.** Drag a server in the list on the left to another place (or use "Nach oben" / "Nach unten" in its right-click menu, or Alt+arrow keys). The order is stored encrypted in your directory account and follows you to every device.
- **Import a Discord server's structure.** Administration > Import takes a Discord server template link and shows what it would add: categories, channels and roles. The import only adds and never changes what is there. Needs a server that is up to date; older servers do not show the tab.
