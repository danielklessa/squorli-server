## New

- **Quick Share.** While a game is detected (Settings > Games) and you are in a voice channel, a gamepad button appears in the voice controls at the bottom left. One click shares the game's window with its audio, without the share dialog, and always sends it as H.264. If the game's window is minimized, the dialog opens instead. Windows only, like the game detection itself.
- **Choose the video codec of a share.** The share dialog offers VP8, as before, or H.264, and says what the chosen one is good for. VP8 is preselected; for the window of a detected game it is H.264.

## Improved

- **The share dialog has two tabs,** "Windows" first, then "Entire screen".
- **Windows in a useful order.** Detected games come first, then windows in full screen, then everything else by name. Windows only; elsewhere the list is sorted by name.
- **A window's audio is shared from the start.** "Share this window's audio" is ticked when you pick a window and can be unticked. Squorli's own windows never carry audio, and an entire screen's audio stays off until you tick it. Windows only.

## Fixed

- Desktop widgets, such as Rainmeter skins, are no longer offered as windows to share. Windows only.
