## New

- **Your settings are stored encrypted.** With a directory account your settings follow you to every device, and from now on the app encrypts them before they leave your computer. Only you can read them, not even the directory's operator. Settings stored before are encrypted the first time this version starts, and the readable copy is deleted. Once that happened, an older version of the app, or the web client of a server that has not been updated, can no longer save settings to your account and shows an error in the settings until it is updated. Needs a directory that is up to date.
- **Hidden games follow your account.** Which games you never want shown (Settings > Games) is now part of those encrypted settings, so you set it once instead of on every computer. Only the games you hide are stored, never which games are installed, and programs you added yourself stay on the computer they are on. The first time a computer meets your account's list, both lists are joined, so a game you hid there stays hidden. Needs a directory that is up to date; without one the list stays on the computer as before. Windows only, like the game display itself.

## Improved

- **Game icons in Settings > Games.** The list of installed games shows each game's icon. The icons are read from your own computer (Steam, Epic Games, the Xbox app and programs you added), nothing is asked from any server for them. Windows only.
- **Just the game's name.** Next to a member or a friend who plays, the line now shows the icon and the game's name, without "Playing" in front of it.
- The hints in Settings > Games say more exactly what is stored where.
