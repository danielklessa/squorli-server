## New

- **Server accounts.** Servers can now have accounts of their own, shown as `~name`, next to Squorli accounts (`@name`). A server that works without the directory uses only these. You sign in with name and password on any device; nobody can reset the password, so keep it safe. Needs a server with version 0.1.0 or newer.
- **Squorli account and server accounts side by side.** Add a server by its address and sign in or create a server account there, while your Squorli account keeps your friends and direct messages. Starting with "Server accounts only" works too; you can add your Squorli account later under Settings > Account.
- **One sign-in form.** The sign in front of the name decides: `@name` for a Squorli account, `~name` for a server account. Click it to switch.
- **Server account settings.** Change the password or delete the account under Settings > Account; set a profile picture under Settings > Profile. Right-click the server in the rail to sign out of its server account.

## Improved

- Every sign-in is an account now: a bare key stored on one device is no longer offered. If you used a server that way, it asks you once to set up an account; your messages and roles stay.
