## New

- **A start window that takes care of updates.** Squorli now opens with a small start window. It checks for a new version, downloads it with a progress bar and installs it before the app opens, so you always know what is happening. "Install later" skips the wait: the download continues in the background and the app offers the restart as before.
- **The radio turns itself off when there is nothing left to play.** That is when a YouTube video or the last video of a playlist has ended, and about a minute after a Twitch stream is over or when the channel is not live at all. Skipping by hand still goes around the ends of a playlist. Needs a server that is up to date.

## Improved

- The app no longer flashes "No server yet" or the login while it is still loading your servers. The main window appears once it knows what to show.
- See-through window: the start screen and the login card now look like a chat message under the pointer instead of a solid block, and the window shows a thin outline while it has the focus.
