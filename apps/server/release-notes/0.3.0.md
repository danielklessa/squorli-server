The second half of the security review, and a quieter default for the microphone. Please update soon.

## Before you update

- **Back up first** (`squorli backup`): the update changes how sign-in sessions are stored. It runs at the start, members stay signed in, and it cannot be undone: going back to an older version afterwards signs everybody out.
- **The web client can no longer be shown inside a frame** of another site, and its pages only load scripts from your server. If you embed the client in another page, or your proxy injects scripts into it (analytics, widgets), that stops working.
- **A new desktop app follows after this server.** Older apps keep working; the fixes of the app itself (external links, control links) come with it.

## Improved

- **Sessions end properly.** Signing out, an expired session, a kick or a ban now closes the member's open connections at once; a ban also ends all of the member's sessions.
- **A password change signs the account out on its other devices** (server accounts).
- **Sessions are stored so that a leaked database or backup contains no usable sign-in.**
- **Harder to guess passwords:** failed attempts count before the check, and also per account for password change and account deletion. Limits per address treat an IPv6 network as one address, so switching addresses inside it no longer escapes them.
- **The server's request log no longer contains secrets** from addresses (sign-in tokens, signed links).
- **Links from servers and other members** open only when they are ordinary web links.
- **Microphone boost is off by default** on devices that have not stored a choice yet. Members who want it switch it on under Settings > Voice and audio; devices that already stored their settings keep them.

## Fixed

- **Two members signing in at the same moment on a new server** could both become owner. Only the first one does now.
- **Profile and avatar of a server** could be read without being a member.
- **The directory connection** is stricter: the server accepts an answer only for the member it asked about, forged notices from outside no longer make it register again and again, and it no longer reveals who founded the server.
