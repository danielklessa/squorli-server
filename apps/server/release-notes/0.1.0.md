The first numbered release of Squorli Server. Until now the image was published only as `latest`; from this version on you can pin a version in `APP_IMAGE` and read here what changed. It contains everything `latest` had, plus server accounts.

## Before you update

- **Back up first** (`squorli backup`): this version adds a database table for server accounts and a setting for them. The change runs by itself at the start and cannot be undone.
- **Every sign-in now needs an account.** Access with a bare browser key is gone. An account is a Squorli account from the directory (`@name`) or a server account of your server (`~name`). Members who so far signed in with a browser key only keep their messages, roles and membership; at their next sign-in they are asked to set up an account first.
- **A new server needs an account for its owner too:** whoever signs in first with an account, or creates the first server account, becomes the owner. `OWNER_PUBLIC_KEY` can only name the key of a Squorli account.
- **New variable `LOCAL_ACCOUNTS`** (optional): `true` or `false` fixes whether server accounts may be created; empty leaves it to Administration > Server (off by default). Without a directory, server accounts are always allowed.
- **`REQUIRE_ACCOUNT` is gone.** An account is always required now; the variable is ignored and the log warns while it is set. You can remove it from `.env` or your Portainer stack.
- **Desktop app:** older app versions cannot sign in to a server without a directory any more. The desktop app release that follows this version supports server accounts; members of such a server should update the app.

## New

- **Server accounts (`~name`).** Accounts that exist on your server only, with name and password, usable on any device. The password encrypts the account's key on the member's device; the server keeps only the result and can neither read nor reset it. A server without a directory works fully on its own with these accounts. With a directory you allow them under Administration > Server, next to Squorli accounts. Server accounts have their own profile picture; friends and direct messages remain with Squorli accounts for now.
- **One sign-in form.** The sign in front of the name decides: `@name` signs in with a Squorli account, `~name` with a server account. Creating an account offers the Squorli account first, the server account in a second tab where your server allows it.
- **Password and deletion for server accounts** under Settings > Account.
